iPhone setup

  1. Open the StrideBoard Sync Shortcut link from your teacher and tap Get Shortcut.
  2. When it asks, paste your phone token (copy it above). For the server address, use {{ server_url }} (no slash at the end).
  3. Run it once and tap Allow so it can read Steps from Health.
  4. In Shortcuts, open Automation and add two daily automations, at 07:00 and 21:30, that run StrideBoard Sync. Choose Run Immediately.
  5. In Safari, open this site, tap Share, then Add to Home Screen.
  6. Any time you want fresh numbers, tap Sync from Apple Health on your dashboard. (iPhones lock Health data while the phone is locked, so a timed run can miss; this button always works.)
{{ m.icon('phone') }}

Android setup

  1. Install the StrideBoard app file (APK) your teacher shares. Allow "install unknown apps" if asked.
  2. Open it. For the website address, use {{ server_url }}, then paste your phone token.
  3. Tap Allow step access and turn on Steps (and background access if offered).
  4. Tap Sync now. You should see "Sent: Yesterday … Today …".
  5. In your phone's Settings, set the StrideBoard app's battery use to Unrestricted so it keeps syncing in the background.
