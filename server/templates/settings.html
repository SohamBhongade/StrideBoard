iPhone setup

Done once, in two taps. Nothing to type.

  1. {% if shortcut_link %}{{ m.icon('phone', 17) }} Get the iPhone Shortcut then tap Add Shortcut.{% else %}Ask your teacher for the Strideboard Shortcut link, open it and tap Add Shortcut.{% endif %}
  2. Go to Home and tap Sync from Apple Health. The first time, tap Allow so it can read Steps. Tap it again any time for fresh numbers.
{{ m.icon('phone') }}

Android setup

  1. Install the StrideBoard app file (APK) your teacher shares. Allow "install unknown apps" if asked.
  2. Open it and log in like you do here. That links the phone: nothing to copy or paste.
  3. Tap Allow step access and turn on Steps (and background access if offered).
  4. In your phone's Settings, set the StrideBoard app's battery use to Unrestricted so it keeps syncing in the background.
