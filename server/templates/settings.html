iPhone setup

About a minute, done once. No typing: you copy and paste.

  2. {% if shortcut_link %}{{ m.icon('phone', 17) }} Get the iPhone Shortcut then tap Add Shortcut.{% else %}Ask your teacher for the StrideBoard Sync Shortcut link, open it and tap Add Shortcut.{% endif %}
  3. When it asks for your token, paste and tap Done.
  4. Come back here and tap Sync from Apple Health on your Home page. The first time, tap Allow so it can read Steps.
Optional: sync by itself every evening

In Shortcuts, open Automation → New → Time of Day, pick 21:30, choose Run Immediately, and pick StrideBoard Sync. (iPhones hide Health data while locked, so the Sync button on your Home page is the sure way.)

Android setup

  1. Install the StrideBoard app file (APK) your teacher shares. Allow "install unknown apps" if asked.
  2. Open it. For the website address, use {{ server_url }}, then paste your phone token.
  3. Tap Allow step access and turn on Steps (and background access if offered).
  4. Tap Sync now. You should see "Sent: Yesterday … Today …".
  5. In your phone's Settings, set the StrideBoard app's battery use to Unrestricted so it keeps syncing in the background.
